# Habti Navigator

Create a stunning, premium, highly sophisticated web application UI/UX for “Habti Voyage”, a travel, activities, events and corporate experiences company in Morocco.

IMPORTANT BRAND DIRECTION:

Use the visual identity and color palette inspired by https://habtivoyage.com/ .

The interface must feel elegant, premium, immersive, modern and memorable.

Design the app with a luxury travel-tech aesthetic: refined, clean, emotionally engaging, polished, and conversion-driven.

Use the website’s brand colors as the main source of truth. Build the full UI around those colors and extract a coherent design system from them.

Add premium gradients, depth, refined shadows, glass effects, soft reflections, and subtle motion.

GLOBAL DESIGN STYLE:

- Ultra-modern SaaS dashboard + luxury travel brand feel

- Sophisticated, incredible, high-end interface

- Strong visual hierarchy

- Smooth rounded corners

- Glassmorphism used selectively

- Beautiful cards, elegant data tables, premium charts

- Use the best design components and the most visually impressive layout system

- Rich micro-interactions and motion

- Cinematic premium look, but still functional and readable

- Clean spacing and excellent UX

- Responsive design for desktop first, then tablet and mobile

BACKGROUND / VISUAL EFFECTS:

- Add an animated background with “mirror mode”

- The animated background should feel symmetrical and reflective, with a premium mirrored visual rhythm

- Use a subtle animated gradient mesh or abstract fluid light waves mirrored across a vertical axis

- Add very soft floating particles / blurred light orbs / glow accents

- Keep it elegant, not noisy

- Make sure content remains readable with strong contrast

- Background animation should be subtle and premium, not distracting

- Create a “luxury travel atmosphere” with motion and depth
